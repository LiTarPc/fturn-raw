# Quick-start: Raw-сервер 1.0.0 на Linux

Скрипт предназначен для новой установки на Debian/Ubuntu с systemd,
CPU amd64 или arm64 и доступным `/dev/net/tun`. Нужны root/sudo и HTTPS-доступ
к GitHub. Если команд не хватает, скрипт установит только необходимые пакеты
через apt, без обновления всей системы.

## Быстрая установка

На VPS выполните:

```bash
curl -fL --proto '=https' --tlsv1.2 -o quick-start.sh \
  https://github.com/LiTarPc/fturn-raw/releases/download/v1.0.0/quick-start.sh
sudo bash quick-start.sh
```

Скрипт определит архитектуру и внешний интерфейс, скачает соответствующий
сервер из релиза **v1.0.0**, сверит архив с `SERVER-SHA256SUMS`, проверит
архитектуру и версию бинарника, затем настроит:

- службу `fturn-raw.service` с автозапуском;
- UDP-порт `56010`, TUN `ftraw0`, адрес `10.77.0.1/24`, MTU `1420`;
- профиль `auto` и до **трёх устройств одновременно на один ключ**;
- постоянный IPv4 forwarding и правила NAT/forwarding для адресов
  `10.77.0.2`, `10.77.0.3`, `10.77.0.4`;
- случайный ключ в `/etc/fturn-raw/raw.key` с правами `0600`.

В конце будут показаны адрес, порт, MTU и ключ. Вывод содержит данные доступа.
Если VPS за NAT, используйте публичный IPv4 из панели хостера: адрес его
сетевого интерфейса может быть внутренним. Во внешнем firewall/security group
хостера разрешите входящий **UDP 56010** (или выбранный порт).

## Сразу получить ссылку для приложения

Замените пример IPv4 и ссылку звонка своими значениями:

```bash
sudo bash quick-start.sh \
  --public-ip 203.0.113.10 \
  --vk-link 'https://vk.ru/call/join/ВАША_ССЫЛКА'
```

Можно выполнить эту команду и после установки: она покажет параметры
существующего сервера и готовую `fturnraw://` ссылку, не заменяя ключ.
Ссылку можно импортировать на трёх устройствах. В ней по умолчанию используются
TCP к TURN, профиль клиента `rtpopus2`, 10 потоков и полный туннель.

## Проверка и параметры

```bash
sudo bash quick-start.sh --check
sudo bash quick-start.sh --port 56010 --devices 3 --mtu 1420 --interface ens3
sudo systemctl status fturn-raw.service
sudo journalctl -u fturn-raw.service -n 50 --no-pager
```

`--check` не устанавливает пакеты и не изменяет сеть или файлы установки.
Порт: `1..65535`; число устройств: `1..64`; MTU: `576..1500`.
Значение MTU клиента должно совпадать с серверным.
Внешний интерфейс определяется автоматически; `ens3` — только пример.

Повторный запуск для управляемой установки не скачивает сервер заново,
не создаёт дубликаты правил и сохраняет ключ. Несовпадающие параметры,
ручные изменения служебных файлов и сторонняя установка приводят к отказу
до перезаписи сервера. Автоматического обновления старых установок этим
скриптом нет; для них используйте `docs/raw-server.md`.

## Удаление и ошибки

```bash
sudo bash quick-start.sh --uninstall
```

Удаляются только служба и файлы, созданные quick-start, а также её точные
правила iptables с комментарием `fturn-raw-quick-start`. Ключ сохраняется.
После удаления можно запустить установку с новыми параметрами и прежним ключом.
Общие правила firewall, другие службы и системный маршрут не очищаются.
IPv4 forwarding при удалении автоматически не выключается: он может быть
нужен другим службам. Удаляется только собственный файл sysctl.

Если установка не завершится, скрипт остановит созданную службу, удалит
частично добавленные собственные правила и файлы, восстановит исходное
значение IPv4 forwarding. Ключ, в том числе созданный в неудачной попытке,
будет сохранён. Уже установленные необходимые системные пакеты не удаляются.

Успешная установка проверяет службу, TUN/MTU и принадлежность UDP-сокета
процессу сервера. Затем проверьте подключение из своего приложения:
проверка скрипта не заменяет проверку внешнего firewall и пути через TURN/VK.

## Проверка самого скрипта

Скачайте `SHA256SUMS` из того же релиза и проверьте строку `quick-start.sh`:

```bash
curl -fL --proto '=https' --tlsv1.2 -o SHA256SUMS \
  https://github.com/LiTarPc/fturn-raw/releases/download/v1.0.0/SHA256SUMS
grep '  quick-start.sh$' SHA256SUMS | sha256sum --check --strict
```

Автоматические тесты: `scripts/test-server-quick-start.py`. Они проверяют
установку, повторный запуск, удаление, ссылки, NAT для нескольких устройств,
занятый порт, пересекающуюся сеть, неверный SHA-256, архитектуру и очистку
после сбоя запуска. Тесты работают во временных каталогах с подменёнными
systemd/ip/iptables/sysctl/download-командами и не меняют сеть машины.
