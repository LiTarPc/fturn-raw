# FturnRaw core 1.1.0

## Windows x64

Распакуйте fturn-raw-client-1.1.0-windows-amd64.zip. Рядом с raw-client.exe должен находиться включённый в архив wintun.dll разрядности amd64. Запускайте из терминала с правами администратора:

    .\raw-client.exe --version
    .\raw-client.exe -peer VPS_IP:56010 -links VK_CALL_URL -obf-key-file raw.key

Параметры сервера, ключ, профиль и MTU должны совпадать. Профили rtpopus2/rtpopus3 и прежние параметры подключения сохраняются.

## Linux amd64 / arm64

Выберите архитектуру сервера/ПК и распакуйте соответствующий клиентский ZIP:

    ./raw-client --version
    sudo ./raw-client -peer VPS_IP:56010 -links VK_CALL_URL -obf-key-file raw.key

Для TUN и настройки сети нужны соответствующие системные права. Этот выпуск не подтверждает совместимость с Linux 3.4/MIPS-роутерами.

## Android arm64

Termux-пакет собран с fturntermux и использует системный TUN; требуются root и доступный TUN.

VpnService-пакет содержит arm64-v8a/libfturnraw.so. Несмотря на расширение .so, это PIE-исполняемый файл для запуска процессом приложения, а не JNI-библиотека для System.loadLibrary. Приложение передаёт TUN fd либо использует предусмотренный SOCKS-режим. Отдельное вложение libfturnraw.so содержит тот же файл.

Контракт Android-хоста и CAPTCHA: internal/captchaipc/PROTOCOL.md. Расширенный CAPTCHA-режим требует совместимого браузерного хоста приложения и включается явно через -advanced-captcha. Консольная сборка сама не создаёт Android WebView. Автоматическое прохождение не гарантируется провайдером.

## Сервер

Используйте quick-start.sh и QUICK-START.md из этого же релиза либо инструкции docs/raw-server.md. Quick-start закреплён на версии 1.1.0 и проверяет SERVER-SHA256SUMS. Скрипт выполняет установку только после явного запуска пользователем.

Сервер 1.1.0 и клиент 1.1.0 используют прежние wire-профили и ключи. Обновление сервера даёт исправления сохранения/освобождения lease. При потере транспорта освобождение после аварии может ждать lease TTL; goodbye остаётся best effort.

## Проверка файлов

SHA256SUMS покрывает все вложения релиза. CLIENT-SHA256SUMS и SERVER-SHA256SUMS покрывают соответствующие ZIP. Windows-файлы и самостоятельные ядра не имеют цифровой подписи.
