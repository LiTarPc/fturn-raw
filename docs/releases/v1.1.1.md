# FturnRaw 1.1.1

Клиентское ядро основано на проверенной captcha.2. При обычном переносе TCP-соединения между TURN-каналами ядро ждёт, пока опустеет локальная очередь старого канала. Пакеты без данных, включая обычные ACK, больше не запускают такой перенос. Быстрый переход при ретрансмиссии сохранён. В диагностике `flowlet_moves` отдельно считает переносы после паузы.

Правка уменьшает риск, что новые данные обгонят ранее поставленные в очередь пакеты. Скорость на мобильной сети менялась между пробами, поэтому выпуск не обещает прироста Мбит/с.

Клиент совместим с RAW-сервером 1.1.0. Существующие профили и ключи подходят, а серверные сборки 1.1.1 используют тот же протокол. В релизе есть клиенты для Windows, Linux и Android, серверные архивы, `SOURCE.json` и `SHA256SUMS`.
