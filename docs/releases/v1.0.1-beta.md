# FturnRaw 1.0.1-beta — core reliability

This is a prerelease of the client and server cores. The Windows interface remains 0.1.13; UI audit fixes are a separate next stage. Existing stable releases are retained and this beta is not marked Latest.

## Fixes

- Enforce TURN write deadlines on the actual transport. Bound maintenance writes and abort a relay write that is stuck waiting for CreatePermission.
- Respect context cancellation during DNS, TCP/UDP dial and TURN Allocate. Bound graceful deallocation and close the physical socket before waiting on transaction cleanup.
- Make TURN transaction shutdown idempotent, stop retransmission timers, prevent transactions starting after close, and release failed initial sends.
- Retain a device group's server-side IPv4 lease across complete worker loss for the remainder of its 90-second authenticated-activity window. An orderly final worker close releases the slot immediately. Expired leases do not evict live devices.
- Remove a failed server worker only if it is still the exact session stored at its relay endpoint. A late error cannot delete its replacement.
- Retry an authenticated device-limit rejection for up to two minutes of consecutive rejections, allowing stale sessions to expire after a client crash. Existing devices are never displaced; cancellation remains available.
- Correct the audited SOCKS bridge source: preserve TCP upload after the remote write half closes, remove expired UDP readers/flow entries, and reclaim the 128-destination capacity. This bridge existed only in the audit workspace, not the published v1.0.0 CLI. Its corrected package and tests are included; this release deliberately does not add a new SOCKS CLI mode to the published client.

## Compatibility and upgrade

Update both cores to obtain the server lease/replacement fixes and client cancellation/retry fixes. The rtpopus2/rtpopus3 wire formats and existing connection links are unchanged. Address continuity is bounded by the lease window and the server process lifetime; this does not promise TCP survival through a server restart or arbitrarily long outages.

Windows installers/portable packages contain the updated core with the existing UI. Linux amd64/arm64 and Android arm64 client packages, and Linux amd64/arm64/Windows amd64 server packages follow the v1.0.0 release layout. SHA256SUMS covers the published assets. The executables/installer remain unsigned.

## Validation

The release pipeline requires Windows and Linux core tests, the separate TURN and shared bypass suites, Linux race checks for rawvpn/rawsocks/turndial and TURN, native package checks and complete checksums before publication.

Regressions exercise blocked Allocate over TCP and UDP, actual transport write deadlines, pending permission deadlines, stale server send failures, address retention and expiry, device-limit recovery, both TCP half-close orders, UDP idle recovery and more than 128 sequential UDP destinations.

Local Windows amd64 core/TURN suites and go vet passed during preparation. These tests use loopback TURN, in-memory TUN devices and gVisor where applicable. They do not constitute real VK/VPS, kernel TUN/NAT, Android VpnService or multi-hour soak validation. Use this beta for controlled testing.
