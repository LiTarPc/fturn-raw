# FturnRaw 1.1.0

Стабильный самостоятельный выпуск клиентского и серверного RAW-ядра. Версии обоих компонентов — 1.1.0. Основа — проверенный RAW 1.0.1-beta.android.7 из Fturn Android v4.3.8, commit 5b82036e5924002fd7f1b2b8dc197c60509cc3ad. Происхождение и точный список файлов сохранены в SOURCE.json и docs/provenance.

## Изменения после 1.0.1-beta

- Корректное завершение RAW: callback отмены остановлен/дождался завершения до открытия deadline для goodbye. После установки read deadline проверяется отмена до ReadFrom. Сохраняются немедленное прерывание зависших записей, sticky abort и ограниченный TURN teardown.
- Жизненный цикл SOCKS UDP-ассоциаций, освобождение простаивающих ресурсов и приём неопределённой IPv6-подсказки UDP ASSOCIATE при IPv4 relay.
- RAW HEALTH: различение принятых, расшифрованных и допустимых кадров, PONG, обновлений allocation/ChannelBind и причин закрытия.
- Полная ёмкость очереди отдельного tcp-flow канала. Общая packet-очередь сохраняется; это не обещание устранения любых потерь/обрывов.
- Расширенный браузерный PoW/CAPTCHA IPC для совместимого Android-хоста: отдельные стадии захвата и решения, ограничения повторов, ручной fallback и защита чувствительных данных. Режим включается явно.
- Сохранены несколько устройств на одну ссылку, прежние wire-профили и конфигурации сервера.

## Вложения

Клиенты: Windows amd64, Linux amd64/arm64, Android arm64 Termux и VpnService. Android libfturnraw.so — запускаемый PIE, не JNI. Серверы: Linux amd64/arm64 и Windows amd64. В комплекте лицензии, matching amd64 Wintun для Windows, quick-start 1.1.0, SOURCE.json и SHA256SUMS.

Windows UI и Android APK имеют отдельную нумерацию и свои релизы. Этот core-only релиз не меняет Latest для существующего автообновления Windows UI.

## Проверки и ограничения

Публикация выполняется после Windows/Linux Go-тестов, повторных регрессий завершения RAW, Linux race-проверок RAW/SOCKS/TURN, отдельного TURN-fork и shared/bypass, проверки browser fixture, архитектуры бинарников и полного набора checksums.

В исходном исправлении android.7 обе гонки воспроизведены детерминированно: старый callback без join и чтение без post-set ctx check давали ошибки. Совмещённое исправление прошло независимые целевые серии и встроено в стабильное Android-приложение 4.3.8.

Счётчик ready отражает готовность канала, а не гарантированную доступность любого сайта. Известны временные сетевые/серверные тайм-ауты и потери при переполнении очередей; расширенный CAPTCHA-режим не гарантирует принятие проверки провайдером. Новый многосуточный прогон Windows/Linux и испытание MIPS-роутера в рамках этого выпуска не выполнялись.

## Установка

Проверяйте SHA256SUMS, сохраняйте исходные ключи и конфигурации и используйте архитектуру своей системы. Документы: docs/raw-core-1.1.0.md, docs/QUICK-START.md и docs/raw-server.md.
