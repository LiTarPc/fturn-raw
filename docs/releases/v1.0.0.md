# FturnRaw 1.0.0 — до трёх устройств на один ключ

Клиентское и серверное Raw-ядра обновлены до **1.0.0**.
Один сервер по умолчанию обслуживает **до трёх устройств одновременно**
с одной ссылкой подключения и одним ключом. Подключение следующего устройства
в пределах лимита больше не вытесняет уже подключённое.

Сервер назначает каждому устройству отдельный внутренний адрес. Добавлены
проверки распределения адресов, преобразования пакетов, переподключений и
освобождения занятых мест. Лимит задаётся параметром `-max-devices` (по умолчанию 3).

## Версии компонентов

| Компонент | Версия |
| --- | --- |
| Клиентское Raw-ядро | 1.0.0 |
| Серверное Raw-ядро | 1.0.0 |
| Интерфейс и установщик Windows | 0.1.13 |

Интерфейс Windows сохранён от 0.1.13; внутри нового пакета находится ядро 1.0.0.
Название пакета и тег относятся к выпуску ядер 1.0.0.

## Что скачивать

- **Windows x64:** `fturn-raw-1.0.0-windows-x64-setup.exe` — установщик;
  `fturn-raw-1.0.0-windows-x64-portable.zip` — переносимая версия.
- **Linux:** клиентские архивы для amd64 и arm64.
- **Android-приложение, arm64:** архив `android-arm64-vpnservice` содержит
  `arm64-v8a/libfturnraw.so` для интеграции в приложение. Это исполняемое ядро
  для VpnService; готового APK в этом релизе нет.
- **Android Termux, arm64:** отдельный архив `android-arm64-termux`;
  для создания TUN и настройки VPN требуются root и поддержка ядром устройства.
- **Сервер:** отдельные архивы для Linux amd64, Linux arm64 и Windows amd64.
- **SHA256SUMS:** контрольные суммы всех файлов выпуска;
  CLIENT-SHA256SUMS и SERVER-SHA256SUMS содержат соответствующие подмножества.

## Обновление и совместимость

Для одновременного подключения нескольких устройств нужен **сервер 1.0.0**.
Обновление только клиента не добавляет эту возможность на старом сервере.
Существующие ссылки и ключи остаются пригодны для подключения.

При обновлении собственного сервера необходимо расширить forwarding/NAT на весь
пул адресов устройств. Для стандартного лимита 3 используются 10.77.0.2,
10.77.0.3 и 10.77.0.4. Подробности — `docs/raw-server.md` и пример правил
`scripts/debian/raw-firewall.sh` в исходниках этой версии.

Перед установкой Windows завершите приложение через пункт «Выход» в трее.
Профили и настройки в LocalAppData сохраняются. Приложение и установщик не подписаны.
Linux и Termux требуют настройки маршрутов и DNS средствами интеграции;
ядро не переключает системный маршрут автоматически.

## Проверки

Проверены протокол, несколько клиентов, переподключения, обработка пакетов,
обфускация, тестовые TURN-транспорты, сборки всех указанных платформ,
состав архивов и сохранение настроек при установке/обновлении/удалении Windows.

Серверная сборка 1.0.0 также проверена на двух действующих Linux amd64 VPS:
авторизация, серверный TUN и выход в интернет через NAT для пакетов до MTU 1420.
Три физических устройства одновременно, Android-устройства и Keenetic MIPS
не проходили аппаратную проверку в рамках этого выпуска. MIPS-сборок в релизе нет.

Релиз опубликован из ветки `codex/raw-1.0.0`; основная ветка и прежний
релиз v0.1.13 сохранены. Личные ключи, профили и ссылки звонков в архивы не включены.
