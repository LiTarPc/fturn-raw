# fturn Raw

Экспериментальный Raw IPv4-клиент для Windows с интерфейсом, профилями и сервером для Linux. Клиент передаёт IPv4 через VK TURN; внешний транспорт Windows-клиента — TCP. Это собственный протокол проекта, несовместимый с обычным сервером FreeTurn или qWDTT.

## Установка Windows

Скачайте `fturn-raw-<версия>-windows-x64-setup.exe` на [странице релизов](https://github.com/LiTarPc/fturn-raw/releases). Запустите установщик NSIS и подтвердите запрос администратора. Он установит клиент в `C:\Program Files\fturn Raw`, создаст ярлыки и запись для удаления в настройках Windows. Если WebView2 отсутствует, установщик скачает официальный загрузчик Microsoft, проверит его цифровую подпись и установит Runtime. Для этого нужен интернет.

Перед обновлением или удалением завершите клиент через пункт **Выход** в меню трея. Установщик не завершает VPN принудительно. После установки откройте клиент и добавьте профиль кнопкой **+**: импортируйте ссылку конфигурации или заполните сервер, ссылку VK-звонка, ключ, MTU и число потоков.

Профили и настройки хранятся в `%LOCALAPPDATA%\fturn-raw`. Обновление и удаление программы сохраняют эту папку. Личные серверы, ключи и ссылки звонков не входят в исходники или установщик. При переходе с portable-версии сначала запустите актуальный portable-клиент, чтобы он перенёс старые профили в AppData; либо импортируйте сохранённую ссылку в установленный клиент.

Поддерживаются Windows 10/11 **x64**. Установщик и приложение пока не подписаны сертификатом издателя. Есть также portable ZIP; его нужно распаковать и запускать `FturnRaw.exe` от администратора.

## Возможности

- Весь IPv4 через Raw; блокировка IPv6 и DNS вне туннеля при подключении.
- Выбор текущего внешнего подключения: действующий системный VPN либо обычное сетевое подключение, если VPN выключен.
- Отдельный служебный канал ядра для авторизации VK и TURN, без зацикливания DNS.
- Несколько профилей, импорт и экспорт ссылок с полным набором настроек и встроенным ключом.
- Трей, время активного подключения, статистика трафика, автозапуск и автоматическое подключение.

Текущий серверный прототип рассчитан на **один физический клиент на экземпляр сервера** и до 64 TURN-потоков. Подключение другого компьютера с тем же ключом и адресом может заменить активного клиента. Потоки — соединения с TURN, а не количество ядер процессора. Подробности протокола: [Raw experiment](docs/raw-experiment.md); [Windows UI](docs/raw-windows-ui.md).

## Сборка

Нужны Go 1.26.6+, Node.js 22.12+, Wails CLI 2.13.0 и NSIS 3. Сборка выполняется в Windows PowerShell:

```powershell
go install github.com/wailsapp/wails/v2/cmd/wails@v2.13.0
.\scripts\build-raw-installer.ps1 -Version 0.1.0
```

Скрипт собирает ядро и интерфейс, запускает проверки маршрутов и backend, загружает Wintun 0.14.1 с проверкой закреплённого SHA256 и создаёт NSIS EXE в `dist`. [Описание установщика и проверок](docs/raw-installer.md).

Сервер Linux:

```powershell
.\scripts\build-raw.ps1 -Targets linux-amd64
```

[Установка сервера на Debian](docs/raw-deployment.md). Для каждого экземпляра создайте собственный ключ; приватные ключи и конфигурации не коммитьте.

GitHub Actions собирает Windows-пакет на push/PR. Тег `v0.1.0` запускает публикацию экспериментального релиза с установщиком, portable ZIP и SHA256SUMS. Версия тега должна соответствовать `info.productVersion` в `ui/newservice/wails.json`.
