# FturnRaw — ядро 1.0.0

Ветка `codex/raw-1.0.0` содержит клиентское и серверное Raw-ядро **1.0.0**.
На одном сервере/ключе по умолчанию могут одновременно работать **3 устройства**
с одной и той же конфигурационной ссылкой. Четвёртое подключение отклоняется без
отключения существующих. Лимит задаётся `raw-server -max-devices 3` (диапазон 1–64).

| Компонент | Версия в этой ветке |
| --- | --- |
| Клиентское Raw-ядро | 1.0.0 |
| Серверное Raw-ядро | 1.0.0 |
| Интерфейс Windows | 0.1.13 |

Стабильная ветка `main` и [релиз 0.1.13](https://github.com/LiTarPc/fturn-raw/releases/tag/v0.1.13)
сохраняют ядра клиента 0.1.12 / сервера 0.1.10. Эта ветка публикует исходники
новой версии; отдельный GitHub Release 1.0.0 пока не создан.

При обновлении сервера сохраните существующий ключ, MTU и RTP-профиль.
Обновите forwarding/NAT для всех адресов пула: по умолчанию **10.77.0.2,
10.77.0.3, 10.77.0.4**. Клиенты сохраняют свой адрес 10.77.0.2; сервер
выполняет преобразование адресов и направляет ответы нужному устройству.
Новая версия сервера принимает подключения старых клиентов. Новый клиент
может работать со старым сервером, но его ограничение одного подключения остаётся.

Под «устройством» понимается один одновременно работающий клиентский процесс,
а не постоянная регистрация железа. Подробности освобождения слотов после
отключения/сбоя описаны в [инструкции сервера](docs/raw-server.md).

## Сборка ядер этой ветки

Требуется Go 1.26.6. Скрипты запускаются из PowerShell:

```powershell
go test ./internal/rawvpn ./cmd/raw-server ./internal/config ./internal/session
./scripts/build-raw-server.ps1
./scripts/build-platform-clients.ps1
```

Для сборки Windows-приложения используйте [инструкцию](docs/raw-installer.md).
Его номер остаётся 0.1.13, а встроенное клиентское ядро этой ветки — 1.0.0.

## Начало работы

1. Установите клиент или распакуйте portable и запустите его с правами администратора.
2. Нажмите **+** и импортируйте ссылку профиля либо укажите сервер, ссылку звонка мессенджера, ключ, MTU и потоки.
3. Подключитесь. Перед обновлением завершите клиент через **Выход** в трее.

## Возможности

- IPv4 через туннель; защита DNS и блокировка IPv6 при подключении.
- Профили, трей, таймер подключения и обход сайтов, приложений и RU-сетей.
- Работа поверх текущего VPN или обычной сети, восстановление сети после сбоя.

Профили хранятся в `%LOCALAPPDATA%\fturn-raw` и сохраняются при обновлении. До трёх клиентов на сервер/ключ по умолчанию, до 64 TURN-потоков на клиент.
